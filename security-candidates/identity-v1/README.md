# EduOS — مكوّن تحقق خادمي مرحلي غير مفعّل

حقوق الشركة محفوظة، 2026. رخصة أبوظبي:

NAFAS FOR ARTIFICIAL INTELLIGENCE · CN-6573712

## الحالة
هذا مكوّن مرشح معزول، وليس مسار دخول منشوراً أو ترحيلاً للحسابات أو قاعدة بيانات جاهزة. لا تستورده الصفحات الحالية، ولا ينشئ حسابات أو يمنح صلاحيات أو يغيّر السياسات. لا توجد فيه اتصالات مدارس أو أسماء أو بيانات أشخاص أو بيانات تجريبية بديلة. اختبارات الوحدة المنفصلة محاكاة؛ لا تثبت حماية النشر الحي.

## الحدود المطلوبة عند الدمج لاحقاً
- إعداد الخادم يحدد خدمة المصادقة والمدرسة وبيئة البيانات؛ لا تؤخذ من المتصفح أو اسم النطاق المرسل في جسم الطلب. يرفض النقص بدلاً من اختيار مدرسة أخرى.
- يجب أن تقبل خدمة المصادقة المحددة الرمز، مع فحص جهة الإصدار والمستفيد والانتهاء ومعرّف الجلسة وتطابق صاحب الرمز. فك الرمز وحده ليس توثيقاً.
- بعد التوثيق تُقرأ العضوية والصلاحيات وروابط الطلبة من سجل خادمي موثوق في كل طلب؛ لا يمنح البريد أو الاسم أو الدور المحفوظ بالمتصفح أو بيانات المستخدم الوصفية أي تفويض.
- لا محول قاعدة بيانات مرفق؛ لم يثبت بعد المصدر الإداري المعتمد لربط الحسابات. السجل الفارغ يرفض الوصول، وتعذر السجل يتوقف دون رجوع لمسار قديم.
- للوصول إلى سجل طالب يلزم رابط موثوق ساري من النوع المناسب، مع قراءة نطاق السجل الحقيقي من الخادم، لا تصديق المدرسة أو البيئة المرسلة في الطلب. لا صلاحية تلقائية لكل الطلبة لمجرد كون الحساب إدارياً.
- المكوّن يغطي قراءة الجلسة وقراءة سجل الطالب فقط. لا يفوّض الكتابة أو القرارات أو بقية الأقسام، ولا يفرض مهلة الخمول وحده. على كل نقطة خدمة وقواعد البيانات تطبيق التفويض الخاص بها.
- لا تُستعمل محاكيات الاختبار في النشر. يجب ألا يمكن للمستخدم كتابة سجل العضوية أو روابط الطلبة. يلزم التحقق من إلغاء الجلسات والتزامن والمراقبة وتحديد المعدل عند الربط.

## بوابات قبل التفعيل
1. تثبيت خريطة موثقة للحسابات والأدوار والمدارس والعلاقات دون مطابقة تخمينية.
2. فحص المصادر الحية الحالية وربط المكوّن بمصدر تفويض خادمي فعلي واختباره في بيئة معزولة.
3. اختبار جميع الأدوار، رفض تغيير الدور والطالب، ورفض الوصول عبر المدارس أو بين البيانات الواقعية والتجريبية، والحفظ وإعادة الفتح والاستعادة.
4. مراجعة إعدادات الاستضافة وخطة التراجع والتدرج قبل تغيير دخول الجود. لا يُعامل فشل التحقق الجديد تصريحاً باستعمال القديم.
5. أي تغيير بنيوي للقواعد يراجع ويطبق على المشروعات الثلاثة وفق توجيه نور؛ لا توجد في هذه الحزمة ترحيلات أو تغييرات حية.
