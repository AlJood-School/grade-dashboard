# 🎓 بوابة الجود الذكية — مرشح سجل الربط الخادمي

NAFAS FOR ARTIFICIAL INTELLIGENCE · CN-6573712

## الحالة والنطاق

حزمة اختبار محلية؛ لا تُستورد في المتصفح أو في مسارات البوابة الحالية. لا بيانات مدرسة أو حسابات حقيقية هنا. يقتصر التفويض المرشح على قراءة الجلسة وقراءة سجل طالب مرتبط صراحةً، وليس صلاحيات جميع وحدات المدرسة.

المخطط المرشح **ليس ترحيلاً إنتاجياً**. التمهيد خاص باختبار محلي وبجدول مصادقة اصطناعي؛ يمنع تشغيله على مشروع مدرسة. لا يعمل أي ملف تلقائياً عند حفظ الحزمة في المستودع.

## التشغيل المعزول

يتطلب بيئة لينكس تجريبية بصلاحيات إدارية، وحساب نظام لقاعدة البيانات، ومشغّل الشيفرة ومثبت قاعدة البيانات. يُنشئ المشغّل عنقوداً مؤقتاً باتصال محلي دون منفذ شبكي، ويسجل أوامر الاختبارات وفحص الأنواع. تثبيت حزم التطوير يحتاج اتصالاً لتنزيلها، ولا يتصل الاختبار بمشروع مدرسة.

```sh
sh run-local-tests.sh
```

البيانات مولدة للاختبار فقط. إثبات المصادقة في هذا الاختبار اصطناعي، وليس توقيعاً أو جلسة حية. اختبارات مكوّن الهوية السابقة مرفقة دون تعديل. لا يُثبت ذلك التوافق مع إصدار قاعدة الإنتاج أو امتداداتها.

## حدود الأمان وشروط التفعيل

- يمنع المتصفح من قراءة السجل وكتابته. الدور الخادمي للقراءة فقط ولا يتجاوز سياسات الصفوف، لكنه يستطيع قراءة **كل صفوف السجل**؛ تقييد المدرسة والبيئة في هذه المرحلة داخل المحوّل، وليس عزلاً صفياً لذلك الدور.
- لا مطابقة بالأسماء أو البريد أو بيانات المتصفح، ولا منح تلقائي لأن الحساب إداري.
- فهارس الأشخاص والموافقات المحلية **ليست إثباتاً لوجود الشخص أو لصلاحية من اعتمد العلاقة**. قبل التفعيل يلزم محوّل مصدر مخوّل، وتحقق موثق من سلطة الاعتماد، وربط مباشر بسجل الطالب الفعلي.
- تبقى مطلوبة: مصادقة حية، وصلاحيات اتصال تشغيل محدودة، واختبار تكامل معزول لكل دور، وحفظ عقد الجلسة والخمول والقفل وتغيير كلمة المرور، واختبار التراجع والاستعادة.
- لا ترحيل أو تفعيل أو ربط حسابات ضمن هذه الدفعة. أي تطبيق بنيوي لاحق يخضع لقاعدة المشروعات الثلاثة والضوابط المعتمدة.
