# 🎓 بوابة الجود الذكية — تصحيح إعداد تأكيد الاستعادة

بتاريخ 21 أكتوبر 2026، صُحّح إعداد حفظ سجل المصادقة داخل قاعدة المشروع بعد تشخيص رفض خادمي في محاولة الاستعادة السابقة. يعتمد حارس التغيير الذري على حدث التدقيق الرسمي؛ كان حفظه داخل القاعدة معطلاً. جرى تفعيل الخيار القائم وحفظه، والتحقق من بقائه مفعلاً بعد إعادة فتح الصفحة.

لا تعديل لشيفرة التطبيق أو بنية القاعدة أو حارسها، ولا تغيير مباشر لكلمة مرور أو بريد أو دور أو رابط هوية أو حساب آخر. لا رسالة استعادة إضافية. يحفظ هذا الإعداد سجلات مصادقة المشروع مستقبلاً داخل قاعدته أيضاً، وليس سجل الحساب المحدد وحده؛ وقد يزيد استعمال مساحة التخزين. لا يغيّر أذونات الوصول إلى السجلات.

اجتاز الحارس 86 فحصاً محلياً ببيانات اصطناعية، تشمل رفض التغيير عند غياب الحدث ونجاح التحديث الذري عند وجوده. لم يُختبر تغيير كلمة مرور حقيقية بعد التصحيح، ولا يُعد حفظ الإعداد إثبات نجاح الاستعادة أو الدخول أو جاهزية البوابة.
